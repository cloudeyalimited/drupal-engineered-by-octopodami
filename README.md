# Drupal Engineered by OCTOPODAMI (DEO)

With [Drupal](https://www.drupal.org/) Engineered by OCTOPODAMI (DEO), you can launch a Drupal stack pre-configured for reliability, maintainability, performance, and security.

Our engineers built this 1-Click Amazon Machine Image (AMI) for rapid deployment; a new server is usually ready in about 10 minutes on Amazon Web Services.

Instead of spending countless hours learning the details of a Drupal build, we've packaged our stack with everything you need to publish content on the world's leading cloud platform.

## Features

Drupal Engineered by OCTOPODAMI® (DEO) uses the following technologies:

1. **Drupal 11**: Modern, open-source content management system with the standard profile
2. **Nginx**: Fast, lightweight web server with high performance
3. **Amazon Linux 2023**: AWS-optimised Linux distribution with enhanced security
4. **PHP 8.4**: Modern PHP with improved performance and long-term support
5. **MariaDB 12.3**: High-performance MySQL-compatible database
6. **[Composer](https://getcomposer.org/)**: Dependency manager for Drupal and its modules
7. **[Drush](https://www.drush.org/)**: Command-line interface for Drupal management
8. **Instance ID unlock**: Every server stays closed until you enter its EC2 instance ID
